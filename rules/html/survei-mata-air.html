📋 Form Survei Mata Air

WAJIB LOGIN MUNCUL DI MAP

Satu form untuk satu mata air. Menggantikan form "Spring Monitoring" yang lama.

A. Identitas Survei

Otomatis dari akun + geotag.

Tanggal survei — date —
Nama surveyor — text (dari akun) —
Nomor WA — phone (dari akun) —
Geotag (tap lokasi) — location —
Desa — reverse geocoding otomatis —
Kecamatan — reverse geocoding otomatis —
Kabupaten — reverse geocoding otomatis —
Provinsi — reverse geocoding otomatis —
Tutupan lahan — otomatis dari Dynamic World (GEE) —
Cek duplikat (radius 250m) — select: Baru / Kunjungan ulang —
Kode SpringHub (jika kunjungan ulang) — text —

B. Identitas Mata Air

Nama lokal mata air — text —
Foto 1: titik keluar air (dekat) — photo —
Foto 2: lingkungan sekitar (5-10 langkah) — photo —
Foto 3: arah aliran keluar — photo —
Jenis/tipe mata air — select: Memancar / Genangan / Lereng / Celah batu / Tidak yakin —
Aliran air saat ini dan sepanjang tahun — select: Stabil / Berkurang saat kemarau / Fluktuatif / Kering total / Tidak tahu —
Perbandingan debit 5 tahun lalu — select: Bertambah / Sama / Berkurang / Tidak tahu —
Perkiraan tahun kering (jika mata air mati) — number —
Dulu air dimanfaatkan untuk (jika mata air mati) — text —

C. Kondisi dan Pemanfaatan

Warna air — select: Bening / Agak keruh / Keruh / Kekuningan / Kehijauan —
Pemanfaatan lahan radius 50m — select: Pemukiman / Pertanian / Lahan hijau / Semak / Air / Industri / Tambang / Lahan kosong —
Tutupan lahan radius 50m (Dynamic World) — select: Air / Pepohonan / Rerumputan / Tanaman pertanian / Semak / Area terbangun / Lahan kosong / Vegetasi tergenang —
Pemanfaatan air saat ini — multiselect: Irigasi / Air minum warga sekitar / Air minum desa lain / Mandi cuci / Kolam ikan / Wisata / Cadangan kemarau / Adat / Tidak dimanfaatkan / Tidak tahu —
Perkiraan jumlah KK pengguna — select: <10 KK / 10-50 / 50-100 / 100-1000 / >1000 / Tidak tahu —
Terlihat ancaman? — select: Tidak ada / Ya —
Jenis ancaman — multiselect: Pestisida / Mandi di sumber / Toilet <11m / Sampah / Sumur dalam / Kandang ternak / Bangunan beton / Over-ekstraksi / Tambang / Lainnya —
Sumber informasi — select: Observasi sendiri / Warga sekitar / Orang tua desa / Kelompok masyarakat / Aparat desa —

D. Pengukuran (jika bawa alat)

pH air — number (range 0-14) —
Suhu air (°C) — number (range 5-45) —
TDS (ppm) — number (range 0-5000) —
EC / DHL (µS/cm) — number —
Debit air (liter/detik) — number —
Estimasi debit visual — select: Menetes / Kecil / Sedang / Besar / Tidak diukur —

E. Cerita dan Tindak Lanjut

Cerita, sejarah, mitos — textarea (opsional) —
Bersedia aksi tindak lanjut? — select: Ya / Belum tahu / Tidak —
Aksi yang dibutuhkan — multiselect: Pembersihan sedimen / Penanaman pohon / Pembuatan rorak / Perlindungan regulasi / Lapor desa/dinas / Lainnya —
Total field: ~30+ field (termasuk reverse geocoding otomatis).
