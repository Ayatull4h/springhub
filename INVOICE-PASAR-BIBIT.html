Alur Pasar Bibit

User lapor bibit (via form) → Admin verifikasi → Card muncul di Marketplace → User lain pilih jenis/lokasi + tulis jumlah + klik minta → Admin tinjau permintaan → Jika diacc, user terima notifikasi berisi nomor WA penyedia bibit → User hubungi penyedia → Ambil bibit → Penyedia klik "Selesai" + Penerima klik "Selesai" → Jika salah satu tidak klik selesai, stok bibit tidak akan berkurang.

Catatan: Jika ID pengguna, lokasi, dan jenis bibit sama → tambah stok. Jika satu saja dari 3 aspek berbeda → card baru.
